# School Management System

## Project Overview
The School Management System is a Java Swing desktop application developed using Java, MySQL, and JDBC. It provides a graphical interface for managing students, teachers, subjects, marks, attendance, and fees.

## Requirements
- Java Development Kit (JDK)
- MySQL Server
- MySQL Connector/J
- IntelliJ IDEA or another Java IDE

## Database Setup
1. Install and start MySQL Server.
2. Create a database named `SchoolManagementSystem`.
3. Create the required tables: `users`, `students`, `teachers`, `subjects`, `marks`, `attendance`, and `fees`.
4. Configure your local database connection in `db.properties`, following the project's database configuration.
5. Verify that the database username and password are correct.
6. Keep `db.properties` private. Never upload real database credentials to GitHub.

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Configure the required JDK.
4. Add MySQL Connector/J to the project dependencies if needed.
5. Set up the database and configure `db.properties`.
6. Ensure MySQL Server is running.
7. Run `Main.java`.
8. Log in using a valid application account.
