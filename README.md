# School Management System

## Project Overview

The School Management System is a Java Swing desktop application developed using Java, MySQL, and JDBC. It helps manage school records through a graphical user interface.

## Requirements

* JDK
* MySQL Server
* MySQL Connector/J
* IntelliJ IDEA or another Java IDE

## Database Setup

1. Create a MySQL database named `SchoolManagementSystem`.
2. Create the required tables: `users`, `students`, `teachers`, `subjects`, `marks`, `attendance`, and `fees`.
3. Configure your local database credentials in `db.properties`.
4. Keep `db.properties` private. Do not upload real database credentials to GitHub.

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Add MySQL Connector/J to the project dependencies if needed.
4. Configure `db.properties` with your local MySQL credentials.
5. Ensure the database and required tables exist.
6. Run `LoginFrame.java`.
7. Log in using a valid application account.
