# School Management System

## Project Overview

The **School Management System** is a Java Swing desktop application developed using Java, MySQL, and JDBC. It provides a graphical user interface for managing student records, teachers, subjects, marks, attendance, and fees.

## Requirements

- Java Development Kit (JDK)
- MySQL Server
- MySQL Connector/J
- IntelliJ IDEA or another Java IDE

## Database Setup

1. Install and start MySQL Server.
2. Create a database named `SchoolManagementSystem`.
3. Create the required tables: `users`, `students`, `teachers`, `subjects`, `marks`, `attendance`, and `fees`.
4. Configure the local database connection using `db.properties`, following the project's database configuration.
5. Ensure that the database username and password are correct.
6. Keep `db.properties` private. Never upload real database credentials to GitHub.

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Configure the required JDK.
4. Add MySQL Connector/J to the project dependencies if it is not already configured.
5. Set up the MySQL database and configure `db.properties`.
6. Ensure the database server is running.
7. Open and run `Main.java`.
8. Log in using a valid application account.
